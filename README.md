Project Overview
Carbon Emissions Prediction using Machine Learning
This project predicts per-capita CO₂ emissions for countries using machine learning techniques. It uses real-world socioeconomic and environmental data, such as energy use, GDP, urban population, and GNI, to train a Random Forest Regressor model, which helps visualise and forecast emissions trends over time.

Key Features
- Predictive Analytics: Forecasts emission levels based on historical world development indicators.
- Feature Engineering: Analyzes the impact of GDP, GNI, and urban population growth on sustainability.
- End-to-End Pipeline: Includes data cleaning, Exploratory Data Analysis (EDA), and machine learning implementation.

Tech Stack
- Language: Python
- Libraries: Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- Tools: Jupyter Notebook
